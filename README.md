# Naive Yearly — home page

Only index.html is published. Program and RSVP show TBA on hover, keyboard
focus, and click/tap. Click/tap again to close. Memories links to the Are.na site.
The website uses HTML and CSS only.

## Subscribe
The form submits directly to the Buttondown newsletter naiveyearly. No API key
or Buttondown CSS changes are needed. Buttondown handles its confirmation,
validation and any CAPTCHA on its own page. Test with your own email after
publishing; no test subscription has been submitted automatically.

## GitHub Pages
1. Upload this folder's contents to the root of your GitHub repository.
2. Open Settings > Pages and choose Deploy from a branch.
3. Choose your publishing branch (usually main), folder / (root), then Save.
4. Open the URL shown by GitHub once deployment completes.

Keep index.html, css/, fonts/ and images/ together. The .nojekyll file disables
Jekyll processing; no build tools are needed. When updating an existing
repository, remove the old program.html, memories.html, rsvp.html and unused
gallery script/photos if you want only the home page available at any URL.

## Search engines
The page includes a descriptive title, meta description, semantic heading,
mobile viewport, and social-sharing title/description.
After choosing your final public URL:
- Add a canonical link in the head using that exact absolute HTTPS URL.
- Verify the site in Google Search Console, inspect the home URL and request indexing.
- Link to the site from your newsletter, Are.na and relevant project profiles.
- Keep visible dates, event description and future program information current.
- A sitemap is optional for this one-page site. If added, use the final public URL.
Do not add guessed domain names or placeholder URLs to published metadata.
The Memories link opens a new tab. The attached favicon is bundled as favicon.png.
